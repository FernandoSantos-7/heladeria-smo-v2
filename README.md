# Ice Cream Shop POS & Management System (v2)

An end-to-end full-stack web application designed to manage sales, inventory, and customer orders for an ice cream parlor. Built with a robust **Python/Django** backend and a dynamic **React/Vite** frontend.

* **Live Demo (Frontend UI):** [heladeria-smo-v2.vercel.app](https://heladeria-smo-v2.vercel.app)

---

## Status: Production-Ready Architecture (~85% Complete)

The core architectural components, relational database management, and client ordering workflows are fully structured and operational. 

> **Architecture Note:** The frontend UI is deployed on Vercel for immediate public preview[span_0](start_span)[span_0](end_span). The Django backend and local SQLite database handle data models and API services designed for seamless local execution or containerized cloud deployment[span_1](start_span)[span_1](end_span)[span_2](start_span)[span_2](end_span).

## Key Features

* **Payment Gateway Integration:** Integrated with Mercado Pago API for processing real-time local transactions[span_3](start_span)[span_3](end_span).
* **Order Management:** System to handle point-of-sale customer orders, flavor tracking, and ticket processing[span_4](start_span)[span_4](end_span).
* **Robust Backend Logic:** Powered by Django to manage REST APIs, business rules, and secure data handling[span_5](start_span)[span_5](end_span).
* **Dynamic Frontend UI:** Built with React and Vite for a highly responsive, modern user experience[span_6](start_span)[span_6](end_span).
* **Relational Database:** Out-of-the-box data storage utilizing SQLite for fast query processing and easy local setup[span_7](start_span)[span_7](end_span).
